## Struktur Repository

Secara umum, struktur repository ini adalah sebagai berikut:

```text
CAK2EAB4-praktikum-struktur-data/
├── README.md
├── .gitignore
│
├── Modul 01/
│   ├── laporan-praktikum.md
│   │
│   └── Unguided/
│       ├── Program/
│       │   ├── unguided1.cpp
│       │   ├── unguided2.cpp
│       │   └── unguided3.cpp
│       └── Output/
│           ├── output-unguided1-1.png
│           ├── output-unguided1-2.png
│           ├── output-unguided2-1.png
│           ├── output-unguided2-2.png
│           ├── output-unguided3-1.png
│           └── output-unguided3-2.png
│
├── Modul 02/
│   └── ...
│
└── Modul 03/
    └── ...
```

Struktur yang sama digunakan untuk modul-modul praktikum berikutnya.

* **`Modul XX/`**
  Menyimpan seluruh berkas yang berkaitan dengan modul praktikum tertentu.

* **`laporan-praktikum.md`**
  Berisi laporan praktikum untuk modul tersebut, mulai dari dasar teori, hasil praktikum, pembahasan, hingga kesimpulan dan referensi.

* **`Unguided/Program/`**
  Berisi source code C++ dari soal-soal unguided pada setiap modul.

* **`Unguided/Output/`**
  Berisi screenshot atau dokumentasi hasil eksekusi program unguided.
